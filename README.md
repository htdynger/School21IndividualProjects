## solved

in `~/solved` i put solved projects. just replace your clonned repos, with eponymous folder.
what u need to do:
1. git clone ssh://example.git (put link from "Task" in project)
2. git checkout -b "develop"
3. replace school21 project folder with my project folder. (just drag&drop folder from ~/School21IndividualProjects/solved/projectname into folder containing the repo from school21)
4. git add . (make sure you in school21 repo in branch develop)
5. git commit -m "solved"
6. git push origin develop
7. check gitlab ui, make sure everything is okay
8. if it didn't work out, that's a skill issue

i already tested projects for clang-format, cppcheck, valgrind, input/output & etc..
